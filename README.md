# 関西大学 千里山キャンパス 3D MAP (Apple Maps Style)

Apple Mapsの3Dレンダリング（ダークモード・写真1）および航空写真サテライトビュー（昼モード・写真2）を忠実に再現した、関西大学 千里山キャンパスのインタラクティブ3Dマップです。

## 主な特徴・再現ポイント

1. **昼モード ＆ 夜モードの完全切り替え（Apple Park風 窓発光 ＆ 博物館正面の花火演出）**
   - **Apple Park スタイルの発光窓＆水平ルーバー**: Apple MapsのApple Park（リング棟・Steve Jobs Theater・ビジターセンター）の光り方を参考に、全校舎に「白い立体水平ルーバーフィン」「足元の接地発光リム」「温かみのあるクリーム・シャンパンゴールド（`#ffebb3`）に内側から面発光する連続リボン窓＆垂直マリオン」を実装。
   - **ダークモード限定・博物館正面の打ち上げ花火モーション**: 夜モード（ダークモード）に切り替えると、関西大学博物館（簡文館）の正面広場から光球が尾を引いて打ち上がり、上空で華やかな花火（ゴールド、サクラピンク、シアン、マゼンタ）が軽やかに咲いてドームを照らすアニメーションが稼働します。
   - **昼モード（写真2再現）**: 鮮やかな青空と太陽光、赤レンガの学舎、緑青銅板ドーム、中央グラウンドの赤い陸上トラックや緑の人工芝、テニスコートをリアルに再現。
   - **夜モード（写真1＋Apple Park再現）**: Apple Maps特有のスレートブルー＆ディープネイビーの立体陰影、内側から温かく輝く校舎群、光輝くネオン調POIピン、高速道路を走る車のヘッドライト。

2. **象徴的な建築・ランドマークの精巧な3Dモデリング**
   - **関西大学 総合図書館**: 赤レンガの外観、屋上の2列の大型ソーラーパネル、正面大階段、スターバックスのテラス席。
   - **関西大学博物館 (簡文館)**: 村野藤吾設計の円形ホール、エメラルドグリーンの緑青ドーム屋根、扇状ウィング。
   - **KUシンフォニーホール & ディノア**: 扇状にカーブした赤レンガ建築と、段々畑状に緑化された屋上芝生庭園テラス。
   - **尚文館**: 赤レンガベースとメタリックシルバーの半円筒かまぼこ型ヴォールト屋根。
   - **以文館**: キャンパス手前に広がる長大棟、両端の2基の円筒ドーム塔、中央天窓。
   - **正門・時計塔・第一診療所**: 表玄関のレンガ門柱、白い四角柱の記念時計塔、クリニック棟。
   - **レストラン チルコロ (円神館)**: 特徴的な完全円形建築と屋上天窓。
   - **中央体育館**: 巨大な白いアーチ・ヴォールト大屋根。
   - **東体育館**: 屋上に配置された青×緑の全天候型テニスコートと防球フェンス。
   - **中央グラウンド**: 400mオールウェザー陸上トラック、内側人工芝サッカーフィールド、ナイター照明塔。
   - **北グラウンド (野球場)**: 本格的な扇型フィールド、内野黒土、外野天然芝、バックネット。
   - **第4学舎 (理工系)**: 高層タワー、実験棟、渡り廊下による幾何学的モダニズム建築。
   - **第2学舎 & 国際部**: 丘陵に沿って連なる校舎群と、国際部屋上の円形ガラスドーム。
   - **名神高速道路 & 千里山トンネル**: キャンパス北東を斜めに走る高架道路、トンネル坑口、走行するミニカー群。
   - **周辺の街並み & 植栽**: 関大前通りの商店街・住宅ブロック、キャンパスを彩る180本以上の樹木。

3. **Apple Maps風の洗練されたUI & インタラクション**
   - **3D POIピン**: 空間上に配置されたApple Mapsスタイルのピンとラベル（ホバーで拡大、クリックでフォーカス）。
   - **建物直接クリック (Raycasting)**: 3Dモデルをクリックしても該当施設の情報がポップアップ。
   - **施設詳細カード**: 開館時間、所属学部、歴史、施設概要を表示。
   - **インクリメンタル検索バー**: 施設名・学部・キーワードで即座に絞り込みズーム。
   - **下部ハイライトカルーセル**: 主要スポットへワンクリックでスムーズカメラ移動。
   - **コンパス**: カメラの回転に連動し、クリックで初期角度にリセット。
   - **2D / 3D 切り替え**: 真上からの2D俯瞰と、斜め45度のアイソメトリック3D表示のトグル。

## 起動方法

ブラウザで `map.html` または `index.html` を直接ダブルクリックして開くか、ローカルサーバーで実行してください：

```bash
# Pythonの簡易サーバーで起動する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000/map.html にアクセス
```
